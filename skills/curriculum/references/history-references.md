# 历史学习引用协议 v1

引用先前的讲解、quiz 问答、学习者代码或自由回答时读取本文件。历史记录帮助建立知识联系，但正文必须独立可读，不能要求学习者先翻回去补空缺。

## 正文约束

- 先用有意义的名称和一句必要背景重述旧知识，例如“之前的两步奖励比较采用整轮求和：路线 A 得 −1，路线 B 得 2，因此选 B。”再在相关句末附 `[^history-1]`。不写“U001 里……D01 你就是这样做的”，也不把这些编号换成括号旁注。
- 不说“你已经证明／掌握……”而不核对实际回答；查到转录也不能替代 `progress.md` 与检查点评估。没有证据时只陈述概念，不编造学习者表现。
- 只在旧记录确实支持当前连接时加注；同一段、同一依据合用一注，不为每句常识添加回顾。课程路线、进度汇报、实际作业标识仍可保留单元／步骤 ID。
- 新测验的待答题面、选项、脚注和隐藏数据都不能通过历史答案泄题。历史依据通常放在回答后的反馈中。历史 quiz 预览只能取已经转录的题目和返回结果，不能读取未呈现的工具答案键。
- 每个助手回复、`quiz.explanation` 或其他独立文字字段使用自己的 `history-1` 等局部 ID，全部定义在同一字段末尾。不能借用上一条回复的定义。`history-` 与教材的 `book-` 前缀完全分开。

## 先核对原记录

课程已绑定后，调用只读工具 `curriculum_history`，用旧题目或讲解中的具体短语搜索，例如 `{"query":"路线 A 的两步奖励"}`。工具返回 `archive_id`、`archive_uri` 和事件的完整 `event_id`、原文，并附上相邻的已转录 quiz 问答。无结果时换更具体的词，或读取原本的相关片段；不能从 U001、D01、日期或摘要猜事件 ID。扩展不可用时可读取 `transcripts/archive.md`，核对其开头的 UUID 和原记录前的 `md-log:event`。

选取真正支持这次连接的事件。引用整道 quiz 的比较时，`event_ids` 按原记录顺序包含题目与已返回的回答；引用一段知识输出或自由回答时通常只需一个事件。不得夹带无关事件。原记录过长时，可加 `quote` 指定第一事件中已逐字核对的连续原文；跳转会选择这处文字，没有 `quote` 则定位第一事件的内容起点。

## 格式

采用标准 Markdown 命名脚注，定义一行。可读标签以“回顾·”开头，后接简短内容名，不显示 U001、D01 等内部 ID。链接指向课程原本；`#mdlog-<第一事件 ID>` 是 Foresight 的事件定位 fragment，无插件时链接仍提供转录文件入口。

```markdown
之前的两步奖励比较按整轮求和：路线 A 得 −1，路线 B 得 2，因此选 B。[^history-1] 现在站在回合中途，过去的奖励已确定，下一步动作只能影响未来的奖励。

[^history-1]: [回顾·两步奖励比较](<file:///E:/ZGerx/Tutorials/RL_Hands-On/curricula/deep-reinforcement-learning-hands-on/transcripts/archive.md#mdlog-78dc386ada6f2db0d1566b4dcf6d0e55f22ee161a996593fbe893aa53624dddf>) <!-- history-ref:v1 {"archive_id":"b844295d-db3a-49f3-b645-59f5767443f3","archive_uri":"file:///E:/ZGerx/Tutorials/RL_Hands-On/curricula/deep-reinforcement-learning-hands-on/transcripts/archive.md","event_ids":["78dc386ada6f2db0d1566b4dcf6d0e55f22ee161a996593fbe893aa53624dddf","4001359ab67ae0985a5cb6799605618fbc859d71f34f7f06b8496efca5001849"]} -->
```

上例取自本项目真实转录，不可复制到其他课程当作其学习证据。

| 字段 | 必填 | 含义 |
| --- | --- | --- |
| `archive_id` | 是 | 原本开头 `md-log:archive` 的 UUID；标识课程转录，避免同名笔记或其他课程串联 |
| `archive_uri` | 是 | 原本的绝对 `file:` URI，指向 `.md` 文件，不带 query 或 fragment |
| `event_ids` | 是 | 一个或多个互不重复的 64 位小写十六进制事件 ID，按原记录顺序；第一项为点击目标 |
| `quote` | 否 | 第一事件中逐字核对的连续 Markdown 原文，最多 120 个字符，用于段内选择；不接受摘要或猜测的原话 |

JSON 严格单行，转义规则与教材协议一致：`<`、`>` 写作 `\u003c`、`\u003e`，连续 `--` 写作 `\u002d\u002d`，不要让文字结束 HTML 注释。链接的文件与 `archive_uri` 一致，fragment 与第一事件 ID 一致。

输出前检查：讲解无需翻历史即可理解；普通教学正文无裸单元／诊断出处编号；每个标记在同一字段有定义；UUID、URI、事件 ID 来自原记录；若声称学习者答过，已核对其真实回答；待答题无泄题引用。

## 转录与 Obsidian

`md-log` 把 `[^history-1]` 和定义一起加事件命名空间，变成 `[^history-<当前输出事件 SHA-256>-1]`。引用元数据中的被引事件 ID 不改写。重放、跨会话和工具反馈均不需要全局计数器；代码、普通脚注及注释中的示例不参与转换。

Foresight 使用独立的历史引用组件：阅读视图与实时预览显示回顾标签，悬停渲染所选原事件的 Markdown（题目、实际回答、公式、代码），点击在转录笔记中定位第一事件或 `quote`。优先使用当前阅读副本里的同课程记录；找不到时读取 vault 内的原本，并验证 UUID 与所有事件。不会依据单元编号、相似标题或行号猜来源。原本移动后按 UUID 查找；多份有效候选时要求明确来源，不任意选取。

未知版本或无效数据保持普通脚注；有效格式但原记录缺失时，弹层说明缺失，点击不跳到其他记录。关闭功能或源码模式仍保留原始 Markdown。

规则从新输出生效。旧转录和带哈希的同步区域保留原文；迁移旧自然语言引用需要单独核对，不能自动把所有 U001／D01 替换成任意标签。
